# Quarteto Fantástico — Robótica de Resgate

Site institucional da equipe Quarteto Fantástico, de Apucarana (PR), participante da modalidade Resgate da Olimpíada Brasileira de Robótica (OBR).

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```
